# Домашнее задание 21.2: Основы верстки и простое веб-приложение

## Описание проекта
В рамках домашнего задания были выполнены две задачи:
1. Сверстаны страницы «Главная» и «Контакты» с использованием фреймворка **Bootstrap 5** (хедер, футер, карточки, формы).
2. Создано простое веб-приложение на Python (без использования фреймворков), которое отдает HTML-страницы и принимает POST-запросы.

## Функционал
- **Сервер на Python (`main.py`):**
  - Обрабатывает GET-запросы и возвращает HTML-страницы (`index.html` и `contacts.html`).
  - Чтение файлов реализовано через контекстный менеджер (`with open(...) as file`).
  - Установлен правильный заголовок `Content-Type: text/html`.
  - Реализован прием POST-запроса (дополнительное задание): данные из формы выводятся в консоль сервера.
- **Верстка (Bootstrap):**
  - Использован темный хедер (`header`) и футер (`footer`).
  - Страница «Контакты» содержит форму обратной связи, стилизованную с помощью Bootstrap (карточка, поля ввода, кнопка).

## Как запустить проект
1. Установите Python 3.x.
2. Перейдите в папку с проектом: `cd homework_21_2`
3. Запустите сервер: `python main.py`
4. Откройте в браузере: `http://localhost:8080`

## Структура проекта
- `index.html` — главная страница.
- `contacts.html` — страница с формой обратной связи.
- `main.py` — сервер на Python.
- `.gitignore` — файл для исключения служебных файлов из Git.
